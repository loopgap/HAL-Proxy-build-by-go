# BridgeOS v0.1.0

Historical backfill for the initial pre-v1 BridgeOS release.

- Tag: `v0.1.0`
- Commit: `31820ca0c16c948225e907b397c8535c2276547f`
- Release type: initial pre-v1 capability baseline
- Latest release: no

## Highlights

- Added the `bridge` CLI for case creation, execution, inspection, events, approvals, reports, devices, sessions, and version output.
- Added the `bridgeosd` local HTTP daemon with `/v1` API endpoints.
- Added SQLite-backed case, event, approval, report, device, and session persistence.
- Added the React + TypeScript UI foundation.
- Added CI, Docker support, structured errors, logging, configuration, and baseline tests.

This release is published after the fact so the remote repository has a complete historical release record. It does not change the current code-line version.
