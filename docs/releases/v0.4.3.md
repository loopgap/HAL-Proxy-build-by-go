# BridgeOS v0.4.3

BridgeOS v0.4.3 is a pre-v1 hardening release for local CI, authentication, ownership checks, and release hygiene.

## Highlights

- Hardened backend authentication flow for JWT, API key, CORS preflight, health endpoints, and loopback local trusted mode.
- Tightened owner/admin authorization for case events, report builds, reports, and paginated case listing.
- Fixed configuration loading so environment overrides and validation apply consistently.
- Expanded Go and UI test coverage, including CLI coverage, middleware coverage, store migration tests, UI page tests, and Case Detail E2E.
- Added `scripts/local-ci.ps1` and `scripts/release-preflight.ps1` for local pre-release validation.
- Added a manual release backfill workflow for missed GitHub Release creation without using `gh`.

`v0.1.0` remains only as a historical prerelease backfill and is not the latest release.
