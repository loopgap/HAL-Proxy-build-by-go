# BridgeOS v0.4.4

BridgeOS v0.4.4 is a patch release focused on security hardening and vulnerability remediation following a comprehensive codebase security audit.

## Highlights

### 1. API Key Constant-Time Comparison Hardening (Low/Medium Risk)
- Fixed a timing attack vulnerability in `withAPIKeyClaims` and `APIKeyAuth` where the dummy hash comparison used a shorter string ("dummyhashvalueforconstanttimecomparison123") instead of matching the full 64-character SHA-256 hex string length.
- Standardized the comparison path to ensure `crypto/subtle.ConstantTimeCompare` performs a strictly constant-time check under all invalid API key scenarios, completely shutting down network-level timing side-channel leakage.

### 2. Local-Trust Loopback Bypass Mitigation (High Risk)
- Mitigated a potential authentication bypass when the daemon is deployed behind local reverse proxies (such as Nginx, Caddy, or Ingress proxies).
- Updated `shouldTrustLocalRequest` to resolve the client IP using `middleware.GetClientIP` (which safely honors `BRIDGEOS_TRUSTED_PROXIES` configurations).
- Ensured loopback bypass is only allowed when BOTH the immediate remote TCP address AND the proxy-resolved client IP are verified loopback addresses, preventing external spoofed or forwarded requests from gaining unauthenticated service/agent status.

### 3. Stability and Release Hygiene
- Bushed version references across all configuration files, workflow pipelines, and APIs to `v0.4.4`.
- Verified and passed 100% of all local tests, Vitest UI components, Playwright E2E integration suites, and release preflights.
